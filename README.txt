SKYWORLD GLOBAL MANAGEMENT WEBSITE — NAVY, GOLD & MARITIME THEME

RUN IN VS CODE
1. Extract SKYWORLD_GLOBAL_MANAGEMENT_WEBSITE.zip.
2. Open VS Code > File > Open Folder.
3. Select the extracted SKYWORLD_GLOBAL_MANAGEMENT_WEBSITE folder.
4. Install the "Live Server" extension by Ritwick Dey if needed.
5. Right-click index.html > Open with Live Server.

FILES
- index.html: page content
- style.css: responsive navy/gold maritime design
- script.js: mobile navigation and demo enquiry form
- assets/skyworld-logo.jpg: cropped emblem from the supplied letterhead

BEFORE PUBLISHING
- Add your verified official email in script.js (COMPANY_EMAIL).
- The letterhead did not provide an email address, so the page shows a placeholder.
- Check the company name, address, phone numbers and service descriptions before launch.
- Contact form opens the visitor's email app; it does not store submissions online.
- This is a front-end website starter. It has no database, admin panel, CV upload, or online form backend.
- Use only verified licences, certifications and approved vacancy details.
- Hero images and Google Fonts load from the internet.
